# React Weather Dashboard Application #

## Created by Tate Swidorski ##

### Description: ###
The overall project was to develop a Weather Dashboard application that allows the user to search for a city in the United States and view a weather forecast from it. This project utilized public API to fetch weather information.

Here is a link to the API I used if you are interested: https://openweathermap.org/api

This project showcases my interest in web development. I built the frontend with React and JSX, and used Netlify Functions to create a serverless backend for handling API requests, which allowed for a clean and responsive application.

### User Experience: ###
1. Upon entering the Website, the user is greeted with a button to a login or sign-up page before being able to use the weather Dashboard Application.
2. After logging in, they are taken to the weather fetcher where the user can get a weather forecast from any city. They are instructed to use this format: City, State. Users may also utilize a search feature.
3. Upon pressing the ‘Get Weather’ button the user will be able to view the weather forecast for the next five days.
4. In the event that the user types in an invalid city, an error message will be displayed.
5. A user can sign out when finished.

### Notice ###
Frontend and serverless backend which were used to manage state and handle API requests respectively were written by myself. CSS styling for this project was assisted by AI-tools in order to generate a responsive, user-friendly UI.
